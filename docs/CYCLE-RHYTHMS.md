# Cycle rhythms — v0.19

Adds opt-in descriptive phase comparisons in Threads over time for Sanctuary mood, anxiety and energy; explicit Cycle pain; and Sleep time in bed. Each shown phase requires five distinct dates in two completed logged cycles, and a metric requires two eligible phases. Repeated ratings are averaged by date. Sleep uses waking dates and excludes overlaps and daily totals over 24 hours. No default ratings are counted.

Calendar phases use intervals between recorded period starts and current period/luteal assumptions. Unfinished cycles and future starts are excluded. Intervals outside 15–90 days or varying by more than seven days within the window suppress the report, as do pregnancy mode and hormonal contraception. Intervals with incompatible phase assumptions are excluded. These are conservative product gates, not clinical validation. Missing period logs can still distort estimates; historical contraception context is not available. Changing current assumptions can change past grouping.

No hormone measurements, confirmed ovulation, causation, diagnosis or fertility advice is inferred. Source selections are persisted using the existing encrypted settings; no migration or new network request is needed. Evidence dates open the existing connected daily view. Existing rest comparisons and dream tag summaries remain available.
