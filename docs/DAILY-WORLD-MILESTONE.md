# Daily World — 0.6

Home now opens with original lightweight celestial/botanical Canvas ornament, a time-aware greeting and a daily writing prompt. Vertical narrative threads replace the previous grid of generic menu cards. Existing journal sections remain reachable through a horizontal book row.

The daily view connects the existing cycle estimate, today's latest Sanctuary check-in, most recent recorded night, last journal page, unfinished reading, today's medication log and traditional seasonal calendar. Data is never invented for empty states. Medication text reports recorded status only, not whether a prescribed schedule has been fulfilled. A continuing book opens at its saved place; pages open in the existing editor; medication opens its Sanctuary tab.

Users can set a greeting name and choose which daily threads appear. These settings persist in the encrypted store and travel in backups. Restoring an older backup keeps current Home visibility choices. Hiding a Home thread does not delete its data or remove its room.

Limits: the moon helper is still approximate; seasonal dates are traditional fixed calendar dates, not exact astronomical events. Full room themes, custom ordering, illustration assets, advanced personal insights and medication reminders remain on the complete roadmap. This milestone does not claim those features are finished.

Verification: Android journey covers Home-to-saved-book navigation, saved reading text, personalization and reloading its encrypted settings. Existing cycle, Sanctuary, pages, tarot, reading, sleep and privacy journeys remain in the build gate. Screenshot captured for visual inspection. Build outcomes recorded after deliberate execution.
