# Testing Moon alongside your existing Lilyly

Install the milestone preview APK and look for **Lilyly Garden · Moon**. It has its own Android storage. Leave your existing Lilyly and Garden Preview installed; the new icon opens a separate copy.

Try the preview with a made-up page first. To try your own records, use **Settings & privacy → Create encrypted backup** in the old app. Choose a file location and keep the password. Use **Restore from backup** in the new preview, verify the file, review the record count and select **Merge backup**. Existing records with matching IDs keep their current version. Check a journal page, photo and imported book before relying on the copy. The new app does not inherit the old app's lock: enable it in the preview if desired.

## Five checks on the phone

1. From Gallery, select two nonprivate images and share to **Lilyly Garden · Moon**. Give them a collection and a creator credit, turn the phone sideways and keep them. Both cards should open with credit intact.
2. Share a link, close the review and discard it. The collection should be unchanged. With app lock enabled, repeat and check that Lilyly requests unlock before showing the incoming text.
3. Tap the moon on Home. Move back one month and choose a date. **Begin a moon page** should open a scrapbook with that date and phase. First leave without saving; then repeat, add a note and save. **Open this day’s threads** should list only the saved reflection.
4. In Settings, change the hemisphere. Revisit the same date: the illustrated orientation and seasonal festival should reflect the setting, while the principal lunar phase should not change.
5. With large Android font size, open the share review, edit the collection with the keyboard visible and verify the Keep button remains reachable.

These are physical-device checks, not claims that the build has already passed on a Samsung. Existing app records are never required for a test.
