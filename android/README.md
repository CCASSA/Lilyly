# Lilyly

Lilyly is an Android-first private journal, grimoire, cycle tracker, mental-health sanctuary, tarot log, and witchy personal archive.

## Current MVP
- Customizable witchy library home
- Journal, poetry, grimoire, spells, ideas, and dream-book entries
- Typed and pasted text
- Image attachment from Android document picker
- Freehand stylus/finger ink layer with local persistence
- Cycle log with period/symptom history and simple estimates
- Mental-health check-ins, medication list/logs, therapy notes, safety plan, and self-harm incident records without gamification
- Tarot reading log
- Bookshelf and magical calendar starter views
- Global search
- Encrypted local data storage using Android Keystore + AES/GCM
- Southern/Northern hemisphere preference

## Planned integrations
Pinterest, Spotify page soundtracks, Health Connect, handwriting-to-text recognition, print-perfect PDF export, biometric lock enforcement, EPUB/PDF reader, encrypted cloud backup.

## Build
GitHub Actions creates a debug APK artifact on every push to `main`.
